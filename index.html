    Từ cần ôn

      Cài đặt

      Game tự tạm dừng khi bạn mở cài đặt và chạy tiếp khi đóng. Giá trị ngoài khoảng cho phép sẽ được tự điều chỉnh.

      Nguồn dữ liệu (Google Drive)

      Cách tốt nhất: Google Sheets → Tệp → Chia sẻ → Phát hành lên web → chọn đúng tab, định dạng CSV, rồi dán link vào đây. Link chia sẻ thường ("Bất kỳ ai có đường liên kết") của Google Sheet hoặc file CSV trên Drive cũng được, nhưng Google đôi khi chặn tải trực tiếp.

      Hàng 1 là tiêu đề cột. Giáo trình HSK: hsk, bai, hanzi, pinyin, nghia. Giáo trình CĐ: bai, hanzi, pinyin, nghia. Có thể thêm: ma, vidu, hien (ghi 0 để ẩn từ), doc (cụm từ để máy đọc thay chữ Hán, dùng cho chữ đa âm, vd. 行 → 银行).

      Link chỉ lưu trên máy này. Để mọi máy học viên dùng chung, bấm "Sao chép địa chỉ chia sẻ" rồi gửi địa chỉ đó cho học viên.

      Giáo trình CĐ Offline (file Excel trên máy)

      Chọn file .xlsx (hoặc .csv) trên máy này. Không cần mạng. File có cột bai thì game tách theo bài; file không có cột bai thì cả file là một bài, lấy tên file làm tên bài. Có thể chọn nhiều file cùng lúc. Nạp lại file trùng tên sẽ thay bản cũ.

        Giọng đọc

        Giọng đọc lấy từ trình duyệt và máy đang dùng, nên mỗi máy có danh sách khác nhau và lựa chọn này chỉ lưu trên máy này. Giọng tự nhiên nhất thường có trên Microsoft Edge (tên có "Natural") và Chrome ("Google 普通话"); hai loại này cần mạng.

        Âm thanh

        Nhạc nền và hiệu ứng được tạo ngay trong game, không cần file hay mạng. Học viên có thể bật/tắt ở màn Chuẩn bị hoặc nút loa trên cùng.

        Bảng xếp hạng

        Lựa chọn bộ từ vựng, cách chơi, tốc độ và thời gian đang bị khóa (do bấm "Người chơi tiếp theo"). Bấm "Đổi cài đặt" sau khi chơi xong cũng sẽ mở khóa.

        Bảng xếp hạng

        Mỗi bạn giữ điểm cao nhất của mình. Bảng chỉ lưu trong lần mở game này và mất khi đóng thẻ trình duyệt.
